Zero Trust IAM Lab — Microsoft Entra ID

Policy enforced ✓

Problem: simulate a Zero Trust identity and access environment for a small organization, ensuring only authenticated, authorized, and compliant users could reach organizational resources.

What I implemented

  • Created an Entra ID tenant; configured users and security groups
  • Built Joiner-Mover-Leaver (JML) workflows for account and group lifecycle
  • Configured Conditional Access requiring MFA, restricting by user risk, enforcing device compliance
  • Applied group-based RBAC for least-privilege access
  • Validated enforcement across multiple test user scenarios
  • Analyzed sign-in and audit logs to investigate authentication events and hunt identity-based threats

Security concepts demonstrated

  • Zero Trust architecture design end-to-end
  • Risk-based and device-compliance Conditional Access
  • Identity lifecycle management (JML)
