Featured Project

Zero Trust IAM Lab — Microsoft Entra ID

Policy enforced ✓

Simulated a Zero Trust identity and access environment for a small organization, ensuring only authenticated, authorized, and compliant users could reach organizational resources.

What I built

  • Created an Entra ID tenant; configured users and security groups
  • Implemented Joiner-Mover-Leaver (JML) workflows for account and group lifecycle
  • Configured Conditional Access to require MFA, restrict by user risk, and enforce device compliance
  • Applied group-based RBAC for least-privilege access
  • Validated enforcement by testing multiple user scenarios
  • Analyzed sign-in and audit logs to investigate authentication events and hunt for identity-based threats

Outcome & learning

  • Reduced risk of unauthorized access via MFA + Conditional Access
  • Ensured users held only the permissions their role required
  • Automated identity lifecycle to prevent orphaned accounts
  • Improved visibility into authentication events and identity threats
  • Learned to design Zero Trust IAM architecture end-to-end, from policy to log-based verification
